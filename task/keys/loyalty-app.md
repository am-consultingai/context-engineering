# Answer key — loyalty-app (main session only)
K1 architecture: a separate Saleor App service (own repo/folder + own DB), extending through webhooks + app token, NOT core changes/plugins (arch: "Extensibility via webhooks + Apps, not in-process plugins"); app owns points ledger
K2 install/auth: app manifest (permissions e.g. MANAGE_ORDERS/MANAGE_USERS/MANAGE_GIFT_CARD, webhooks, extensions), install via `appInstall`/`manage.py install_app` (`saleor/app/management/commands/install_app.py`), store app token securely
K3 webhook: `ORDER_FULLY_PAID` (`webhook/event_types.py:78`) with a subscription query; verify signature (JWS by default when there's no secret, HMAC when there is: `webhook/transport/__init__.py:7`); async via the Celery worker; retries → idempotency keyed on order id (unique constraint in the ledger); out-of-order (refund/cancel events, e.g. ORDER_REFUNDED/ORDER_CANCELLED/ORDER_FULLY_REFUNDED); downtime → reconciliation job querying orders since the watermark
K4 ledger design: append-only transactions, balance derived or updated atomically, adjustments with audit, no double spend on redeem (locking / unique redemption id)
K5 redemption as store credit: Saleor gift cards (`giftCardCreate` for the customer; usable at checkout via `checkoutAddPromoCode`) or a voucher; avoids core changes
K6 dashboard: App extension mount `CUSTOMER_DETAILS_WIDGETS` / `CUSTOMER_DETAILS_MORE_ACTIONS` (`extensions/extensionMountPoints.ts:19`), iframe + AppBridge, token from the dashboard; no dashboard code changes needed
K7 storefront: account page (`(main)/account/page.tsx`); balance fetched server-side through the app's API authenticated with the customer's session JWT (verify the JWT against Saleor JWKS `/.well-known/jwks.json`), or customer metadata; never expose `SALEOR_APP_TOKEN` to the client; redeem via server action; caching (don't `"use cache"` per-user data)
K8 local stack: new service in `dev/docker-compose.dev.yml` (NOT `saleor-platform/`), on the `saleor-backend-tier` network; webhook target reachable from the worker (`http://loyalty-app:PORT`, not localhost); `HTTP_IP_FILTER_ENABLED=True` (`saleor-platform/common.env`) blocks private IPs → dev override; API on host port 8001; two URLs (browser-facing iframe URL on localhost vs container-internal webhook URL); bootstrap/dev.sh setup installs the app idempotently
